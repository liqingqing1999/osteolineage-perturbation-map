# README: Code for "A pre-registered perturbation–response map of the human osteolineage"

This repository contains the **analysis code** and the **dated pre-registration protocol**
(including all post-hoc amendments) for a single-cell CRISPRi perturbation–response map
of the human osteolineage, built on public data from **GSE319266**.

Per the journal's figure/table policy, **result tables and figures are NOT deposited here**;
they are provided with the manuscript and its supplementary materials. All deposited
quantities can be regenerated from public data with the pipeline in [`code/`](code/).

## Contents

```
code/                    Full pipeline, numbered in execution order
preregistration/         Dated pre-registration protocol (original + amendments A1–A3 + closure)
docs/                    Reference reports (e.g. DEU calibration report)
environment.txt          Software versions used to produce the manuscript figures
CITATION.cff             Citation metadata
LICENSE                  MIT
```

## Pipeline (execution order)

| Step | Script | Purpose |
|---|---|---|
| 1 | `vc_65a_export.py` | Export 50,005-cell matrix from GSE319266 S0v2 objects |
| 2 | `vc_65a2_ucell.R` | AD/OS UCell signature scoring (maxRank = 1500) |
| 3 | `vc_65a3_assemble.py` | Assemble per-unit scores |
| 4 | `vc_65b_disp.py` | Per-unit displacement d_u along the L = z(AD) − z(OS) axis |
| 5 | `vc_65c_null.py` | Per-unit label-permutation nulls (checkpoints resumable) |
| 6 | `vc_65d_verdict.py` | Pre-registered gates: Q1 / G1 / G2 / G3 |
| 7 | `vc_65e_g1v2.py` | Amendment A2: NTC pseudo-unit self-calibration floor for G1 |
| 8 | `vc_66_figures.py` | Figures F2 / F4 / S2 |
| 9 | `vc_67_figures.py` | Figures F1 / F3 |

Steps 1–3 require the downloaded GEO supplementary files; set the environment variables
`GSE319266_L0`, `GSE319266_L1`, `GSE319266_SUPP` to your local paths (see headers of
`vc_65a_export.py`). Steps 4–9 operate on the deposited intermediate tables and only need
`T65_DIR` to point at the directory holding them.

## Reproducibility

- All pre-registered gates were executed **before** full unblinding of G2;
  amendment A3 (partial unblinding of G1) is dated and disclosed in the protocol.
- The manuscript figures (F1–F4, S2) are regenerated by steps 8–9 from the
  intermediate result tables accompanying the manuscript.
- The DEU (differential expression utilization) calibration against the external
  W1c reference is documented in [`docs/calibration_report.md`](docs/calibration_report.md).

## Data availability

- GSE319266 (CRISPRi perturbation-seq): Gene Expression Omnibus.
- GSE169396 (external calibration reference): Gene Expression Omnibus (PMID 34111027).
