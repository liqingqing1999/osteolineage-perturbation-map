## 2. 检出阈值换算（α=0.05/30 Bonferroni，power=0.8）

- 细胞级 MDES @150/组：d* = 0.402（`20_` 原 0.46 为口径变体，本表按显式公式 0.40 为准）

- 反解：4 供体合并口径下要检出 Δc=0.02（天然漂移量级）需每供体约 **400 细胞**（每条件每组合计 ≈1600，为当前 150/供体设计的 2.4 倍）——超出常规 10x 通量预算 ⇒ 设计定位取"检出限≈天然漂移上沿"，不追打 0.016 下沿。

## 3. 直接可写的结论

1. 单供体 150 细胞口径只检得出 ≥2–7 倍天然漂移的操作效应 ⇒ **单供体口径只能当稳健性，不能当主检验**。
2. 4 供体分层合并（150×4/组）检出限 ≈ 0.029，覆盖天然漂移上沿（0.025）⇒ **主检验必须是供体分层合并 + 供体间符号一致性作描述**（与 S5 判据同构）。
3. 阳性对照（PPARG/RUNX2 KD）若首测 |Δc| < 0.03 ⇒ 效应与疾病漂移同量级 ⇒ 应缩条件数、加细胞数（10 基因 × 300×4），而不是扩条件。
4. 效应量报告单位建议用 **天然漂移当量 DEU**（1 DEU = 0.016–0.025），跨数据集可比且不依赖坐标系字面迁移。

## 4. 单位与可迁移性警示

- S5 的 Δc 单位是 D1 流形质心坐标，自采数据坐标系必然重建 ⇒ 阈值不可按字面搬运；可迁移的是两层：①标准化 d*（纯统计量）；②DEU 锚点（效应量参照）。自采数据落地时以自身 σ̂ 重算 SE、以同法估 DEU。
