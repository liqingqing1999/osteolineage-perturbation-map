## 2. Detection-threshold conversion (alpha=0.05/30 Bonferroni, power=0.8)

- Cell-level MDES @150/group: d* = 0.402

- Inversion: under the 4-donor pooled convention, detecting Delta-c=0.02 (natural-drift magnitude) requires ~400 cells per donor (~1,600 cells per condition per arm total, 2.4x the current 150/donor design) — beyond a routine 10x flux budget. The design therefore targets "detection limit ~ upper edge of natural drift" and does not chase the 0.016 lower edge.

## 3. Conclusions carried into the manuscript

1. A single-donor 150-cell readout only detects operational effects >= 2–7x natural drift => single-donor comparisons serve as robustness checks only, never the primary test.
2. The 4-donor stratified pooled convention (150x4/group) has a detection limit ~0.029, covering the upper edge of natural drift (0.025) => the primary test must be donor-stratified pooled, with between-donor sign consistency reported descriptively (same structure as the S5 criterion).
3. If a positive-control knockdown (e.g., PPARG/RUNX2) yields |Delta-c| < 0.03 on first pass, the effect is of the same order as disease drift => shrink the condition count and increase cells (10 genes x 300x4) rather than expanding conditions.
4. Effect sizes should be reported in **natural-drift equivalent units (DEU; 1 DEU = 0.016–0.025 in Delta-c)** for cross-dataset comparability that does not depend on literal coordinate transfer.

## 4. Units and transferability caveats

- The Delta-c unit of S5 is a D1-manifold centroid coordinate; a self-collected dataset necessarily rebuilds its own coordinate system => thresholds must not be transplanted literally. What transfers: (i) the standardized d* statistic; (ii) the DEU anchor as an effect-size reference. A new dataset must re-estimate SE from its own sigma-hat and re-derive the DEU anchor the same way.
